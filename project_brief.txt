Project Title: Student At-Risk Recovery Planner using A* Search  Project Description: Students often ask: “I am behind, what’s the best plan to catch up and avoid failing?” In this project, you are required to develop a Python desktop dashboard (GUI) that uses the A* search algorithm to generate an optimal recovery plan (sequence of actions) that moves a student from At-Risk to Not At-Risk with minimum total cost (time/effort/stress). The system models the student’s situation as a planning problem using features such as attendance, missing submissions, quiz score, learning activity, available study time, and deadline proximity. The GUI must allow users to load/generate dataset or scenarios, run A* algorithm, view the plan and metrics, and test “what-if” constraints.  Functional Requirements 1) Data Input (Student Context)  Load a CSV (e.g., Student_Activity_Data.csv) or generate scenarios (your own dataset).  Minimum fields: attendance_rate, missing_submissions, avg_quiz_score, lms_activity, study_hours_per_week, days_to_deadline.  2) A* Planning Engine (Core)  Implement A* from scratch (open/closed sets, g(n), h(n), f(n) = g + h).  Define: o State: student status (e.g., attendance, missing, score, deadline, fatigue/time). o Actions (≥ 6): Attend_Class, Study_1_Hour, Submit_Assignment, Practice_Quiz, Meet_Tutor, Rest. o Goal: “Not At-Risk” (e.g., risk_score ≤ threshold and missing_submissions = 0). o Cost: effort/time + deadline/fatigue penalties. o Heuristic: estimate remaining effort to reach the goal.  3) Outputs (Dashboard Results)  Show: plan steps, total cost, final risk status/score, runtime, expanded nodes.  Plots (minimum): risk before vs after, action counts.
